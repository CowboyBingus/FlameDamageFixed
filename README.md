# Flame Damage Fixed

Flame Damage Fixed now ships inside the **[Vanilla Plus Megapack](https://github.com/CowboyBingus/VanillaPlusMegapack)**, the
HellForge code mod that holds all twenty-five CowboyBingus Helldivers 2 mods in one download. Each mod is a component
you switch on or off in the pack's settings. Flame Damage Fixed's C source is in
[`src/components/flame_damage_fixed`](https://github.com/CowboyBingus/VanillaPlusMegapack/tree/main/src/components/flame_damage_fixed).

The standalone Lua mod (v1.2 and earlier, for the Lua mod loaders) is on the
[`legacy`](https://github.com/CowboyBingus/FlameDamageFixed/tree/legacy) branch. Its releases and tags are unchanged.
